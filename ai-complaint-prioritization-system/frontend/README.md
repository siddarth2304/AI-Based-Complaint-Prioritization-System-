# Frontend - AI Complaint Prioritization System

React + Vite dashboard for submitting complaints, viewing AI priority results, filtering complaints, analyzing SDG distribution, and updating status.

## Local Setup

```bash
cd frontend
npm install
npm run dev
```

Set the backend URL if it is not running on `http://localhost:8080`:

```bash
export VITE_API_BASE_URL=https://your-cloud-run-url
npm run dev
```
